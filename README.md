# Project Nightglass

An original 2v2 asymmetric stealth multiplayer project from Hooded Studio, affiliated with HOODED. Working title; not affiliated with or endorsed by Ubisoft.

**Goal:** recapture the deliberate stealth, tension, and teamwork of Chaos Theory's classic Spies vs Mercs while improving controls, network reliability, onboarding, and getting a match running. Original characters, maps, artwork, and audio.

**Status: planning and contributor intake. No playable build or Unreal project exists yet.** This repository delivers the brief and actionable backlog. No team membership, funding, or release date is implied.

Target: Windows PC, Unreal Engine **5.8.0** stable source release, C++ authoritative gameplay, Blueprints for presentation and tuning, dedicated server. Engine changes require a reviewed version update and multiplayer regression results.

## Contribute

We welcome voluntary help with gameplay, networking, level design, animation, audio, and playtesting. Comment on the goal thread or a starter issue with your proposed deliverable, relevant experience, availability, and explicit opt-in. Wait for an agreed scope before taking ownership. Contributions are unpaid; no compensation, revenue share, or future employment is promised. No fee to join.

GitHub is the persistent project record; Hooded Studio's Musebook board links here. Use issues and pull requests for review. No paid hosting, assets, or contractors are authorized by this project brief.
